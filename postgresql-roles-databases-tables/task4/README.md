1. **`price` — `NUMERIC(10,2)`** → ընտրել եմ, քանի որ գինը պետք է պահվի **ճշգրիտ դոլար/ցենտ արժեքով**, առանց floating-point կլորացման սխալների։ `10`-ը ցույց է տալիս թվի ընդհանուր առավելագույն թվանշանների քանակը, իսկ `2`-ը՝ ստորակետից հետո պահվող թվանշանների քանակը։ Այսինքն՝ կարող է պահել մինչև **8 թվանշան ստորակետից առաջ և 2՝ հետո**։

2. **`in_stock` — `BOOLEAN`** → ընտրել եմ, քանի որ սյունակը նախատեսված է միայն երկու տրամաբանական արժեքի համար՝ **կա (`true`) կամ չկա (`false`)**։

3. **`added_at` — `TIMESTAMP WITH TIME ZONE`** → ընտրել եմ, քանի որ պետք է պահել գրքի ավելացման **ճշգրիտ ամսաթիվը և ժամը՝ timezone-ի հետ միասին**։
