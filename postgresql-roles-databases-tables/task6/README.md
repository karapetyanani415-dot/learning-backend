`library_staff`-ին տրվել է միայն `SELECT` privilege, դրա համար նա կարողացավ կարդալ `books` աղյուսակի տվյալները, բայց `INSERT` հրամանը ձախողվեց՝ `permission denied` սխալով։

**Արդյունք՝** role-ը ունի միայն անհրաժեշտ **read access** և չի կարող փոփոխել `books` աղյուսակի տվյալները։ Սա ցույց է տալիս **least privilege** սկզբունքի կիրառումը։
